# Community conduct

Participate in good faith. Be direct about technical evidence, assume other
contributors are trying to improve the product, and criticize designs or code
rather than people. Harassment, threats, discrimination, doxxing, and exposure
of credentials or private user data are not accepted.

Maintainers may edit or remove abusive or unsafe content and restrict accounts
that repeatedly violate these rules. Report conduct concerns privately to
`support@valkyrlabs.com`; report security issues to `security@valkyrlabs.com`.
