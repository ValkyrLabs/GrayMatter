# GrayMatter Lite compatibility note

The public product name is **GrayMatter Lite**. Existing `LIGHT` environment
variables, `gm-light-*` scripts, and `graymatter-light-bootstrap` paths remain
supported so installed clients do not break.

Lite is a useful single-user or single-workspace open-source product, not a
demo-only subset. The current installation, source, dashboard, MCP, profiles,
KnowledgePack, local-model, Docker, and SWARM guidance is in
[graymatter-lite.md](graymatter-lite.md).
