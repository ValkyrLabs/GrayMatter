# What was effective, and what was known

An agent can hold the effective time fixed and ask what GrayMatter knew before and after a correction. Use the hosted `omega_temporal_assertions_as_of` operation for typed facts and relationships. The authenticated api-0 OpenAPI document returned HTTP 200 on November 6, 2026 at 22:01 UTC with schema revision 0.9.27. It listed the four operations below. The runtime results here come from tests of the ValkyrAI checkout with synthetic records, mock persistence and access checks.

| Operation | Time inputs | Scope |
| --- | --- | --- |
| `POST /graymatter/omega/tools/temporal-assertions-as-of` | `validAt`, `recordedAt` | Typed assertions on one exact subject in the parent receipt. A correction supersedes its predecessor once both its valid and recorded intervals cover the requested points. |
| `POST /graymatter/omega/temporal/assertions/history` | `validFrom`, optional `validTo`, `recordedFrom`, optional `recordedTo` | Assertions overlapping both windows. The response can carry predecessor and successor references. See the visibility defect below. |
| `POST /graymatter/omega/tools/evidence-relation-read` | `validAt`, `recordedAt` | Typed, versioned GraphLink evidence. The runtime checks each edge's governed fields and hash, both endpoint memberships, and current endpoint and provenance access. |
| `POST /graymatter/omega/tools/supersession-read` | One `asOf` | Explicit supersession edges connecting two receipt members. The runtime applies the same instant to both recorded and valid intervals. This answers the single-instant question. |

For the two-point comparison, obtain a plan with a temporal inspection step and a matching search receipt for **each** recorded time. Supply the same subject, predicate, query and `validAt` for both calls. Each `recordedAt` must equal its own plan's `asOf` and fall at or before the parent receipt's observation. Read access is checked at inspection. Save both plan, receipt, trajectory and assertion references with the dates. Current authorization, source removal, and result limits constrain what comparisons can establish. An empty or capped response cannot establish that a fact never existed.

The hosted regression `backdatedCorrectionAppearsOnlyAfterItsRecordedTime` holds `validAt` at January 15. The original assertion applies from January 1 and was recorded January 2. A correction also applies from January 1 and was recorded March 1. The February 1 read selects the original assertion. The April 1 read selects the correction and identifies its predecessor. Another test covers late arrival, and a third rejects an unauthorized recorded time before loading the receipt. The two hosted service suites passed 25 tests when compiled from the current source under JDK 21.

## Reproduce the original failures

These cases use the hosted `OmegaTemporalAssertionRuntimeService` with the existing test suite's generated entity and permission mocks. They describe behavior observed on the original service source.

1. In `historyReturnsBothCoordinatesAndDerivedReverseSupersession`, assign the correction a fresh provenance ID for which the fixture returns no readable entity. Keep the predecessor readable and request `includeSuperseded=true`. The response contained one row, the predecessor. Its `supersededByRef` still identified the excluded correction. The original service calculated reverse links before checking provenance and endpoints. The regression checks that an absent correction, a correction denied by its row ACL, and a correction with unreadable provenance yield the same view. A readable correction can supersede a predecessor even if the response limit excludes the correction from a history page.
2. Give the as-of fixture two independent, readable assertions with the same subject and predicate, overlapping valid and recorded intervals, and no supersession link. Set the plan and request limits to one. The response returned one row with `completeWithinReceipt=true`. The regression distinguishes a real second eligible row from an exactly full response, for both history and as-of reads.
3. Record a correction of a readable assertion, revoke access to its source memory, then submit the same correction again. The original write path checked the new evidence but could reuse the inaccessible predecessor. The regression requires equivalent missing-resource responses for a missing or inaccessible predecessor, including retries. Failure precedes the idempotency lookup and insert.
4. Omit `recordedTo` and set `recordedFrom` to the plan's recorded-time ceiling. Both ends then denote the same instant. The original history projection could include an assertion spanning that instant. The regression requires the same bad-request response as an explicitly empty half-open window.
