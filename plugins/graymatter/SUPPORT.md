# Community support

GrayMatter Lite community support is public and source-oriented:

- GitHub Discussions: setup questions, ideas, local-model hosts, KnowledgePacks,
  and usage patterns;
- GitHub Issues: reproducible defects and focused feature requests;
- pull requests: tested code or documentation changes;
- `security@valkyrlabs.com`: private vulnerability reports only.

Before asking for help, run `./vaix doctor` and include the failing check,
operating system, CPU architecture, Java/Node versions, and the relevant
redacted log. Never post passwords, tokens, H2 data, tenant identifiers, or
private memory content.

Commercial support and hosted GrayMatter are separate from the open-source Lite
community channel. Lite remains fully usable without purchasing hosted service.
