# Support

Use **GrayMatter: Verify Connection** and inspect the server with **MCP: List Servers**. For Lite, run `./vaix doctor` in its source folder.

Report reproducible errors at [GrayMatter issues](https://github.com/ValkyrLabs/GrayMatter/issues). Include the command, platform and a redacted error message. Keep passwords, bearer tokens and private memory out of reports.
